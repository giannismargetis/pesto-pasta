# Εγκατάσταση του PASTA (για όλους)

## Τι χρειάζεσαι

* Υπολογιστή με **Windows 10 ή 11** (64-bit).
* **Μικρόφωνο** (ακουστικά με μικρόφωνο, κάμερα με μικρόφωνο, ή το ενσωματωμένο του laptop).
* Περίπου **5 GB** ελεύθερο χώρο.
* **Internet μόνο την πρώτη φορά** (για να κατέβει το μοντέλο ομιλίας, ~1,6 GB).
* Κάρτα γραφικών **NVIDIA** κάνει το πρόγραμμα πολύ πιο γρήγορο, αλλά δεν είναι
  απαραίτητη — χωρίς αυτήν δουλεύει απλώς πιο αργά.

## Βήματα

1. Κάνε διπλό κλικ στο **`PASTA-Setup-3.0.0.exe`**.
   * Αν τα Windows δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πάτησε
     **«Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε»**. (Εμφανίζεται επειδή το
     πρόγραμμα δεν έχει ψηφιακή υπογραφή εμπορικής εταιρείας.)
2. Πάτησε **Επόμενο** στα βήματα της εγκατάστασης. Δεν χρειάζονται δικαιώματα διαχειριστή.
   Μπορείς να επιλέξεις εικονίδιο στην επιφάνεια εργασίας και εκκίνηση μαζί με τα Windows.
3. Στο τέλος, άφησε επιλεγμένο το **«Άνοιγμα του PASTA τώρα»**.
4. Την **πρώτη φορά** ανοίγει ένας οδηγός:
   * κατεβάζει το μοντέλο ομιλίας (βλέπεις μπάρα προόδου — μερικά λεπτά),
   * ελέγχει το μικρόφωνο: μίλα και η πράσινη μπάρα πρέπει να κινείται,
   * σου δείχνει πώς το χρησιμοποιείς.

## Χρήση

| Θέλω να… | Κάνω |
|---|---|
| γράψω με τη φωνή μου | κρατάω πατημένο το **δεξί Ctrl**, μιλάω, το αφήνω |
| δώσω εντολή | λέω «**Πάστα,** άνοιξε το Chrome» (κρατώντας το δεξί Ctrl) |
| ακυρώσω | πατάω **Esc** |
| αλλάξω ρυθμίσεις | κάνω κλικ στο εικονίδιο του PASTA κάτω δεξιά στη γραμμή εργασιών |

Παραδείγματα εντολών: «Πάστα, βάλε την ένταση στο 30», «Πάστα, ψάξε στο YouTube Χατζιδάκι»,
«Πάστα, πήγαινε στο Discord», «Πάστα, άνοιξε τις λήψεις».

## Αν κάτι δεν δουλεύει

| Πρόβλημα | Λύση |
|---|---|
| Εμφανίζεται κόκκινο «No microphone» | Άναψε/σύνδεσε το μικρόφωνο. Στα Windows: Ρυθμίσεις → Σύστημα → Ήχος → Είσοδος, διάλεξε το μικρόφωνό σου. Το PASTA το βρίσκει μόνο του σε λίγα δευτερόλεπτα. |
| Δεν γράφει σε κάποιο πρόγραμμα | Αν εκείνο το πρόγραμμα τρέχει «ως διαχειριστής», τα Windows δεν επιτρέπουν σε άλλα προγράμματα να γράφουν μέσα του. |
| Γράφει λάθος γλώσσα | Εικονίδιο → Γλώσσα → **Ελληνικά**. |
| Είναι αργό | Χωρίς κάρτα NVIDIA είναι φυσιολογικά πιο αργό. Κλείσε παιχνίδια ή βαριά προγράμματα. |
| Κάτι άλλο | Εικονίδιο → Πίνακας ελέγχου → **Diagnostics** δείχνει τι λείπει. Το αρχείο καταγραφής βρίσκεται στο `%LOCALAPPDATA%\PESTO\logs`. |

## Απεγκατάσταση

Ρυθμίσεις των Windows → Εφαρμογές → **PASTA** → Κατάργηση εγκατάστασης.
Θα σε ρωτήσει αν θέλεις να σβηστεί και το μοντέλο ομιλίας (1,6 GB) μαζί με τις ρυθμίσεις
και το ιστορικό.

## Ιδιωτικότητα

Η φωνή σου **δεν φεύγει ποτέ** από τον υπολογιστή. Μετά την πρώτη λήψη, το πρόγραμμα
δεν χρειάζεται internet.
