# PESTO + PASTA — Τεκμηρίωση (Ελληνικά)

**PESTO**: πλήρως τοπική, δίγλωσση (ελληνικά/αγγλικά) φωνητική εισαγωγή κειμένου για
Windows με push-to-talk. Κρατάς πλήκτρο, μιλάς, αφήνεις — και το κείμενο εμφανίζεται
όπου βρίσκεται ο κέρσορας.

**PASTA**: επέκταση του PESTO για φωνητικές εντολές («Πάστα, άνοιξε το Chrome και ψάξε …»).
Οι εντολές αναλύονται, «γειώνονται» στην πραγματική κατάσταση της επιφάνειας εργασίας,
περνούν από έλεγχο ασφάλειας, εκτελούνται και **επαληθεύονται**.

Όλα λειτουργούν εκτός σύνδεσης μετά την πρώτη λήψη των μοντέλων. Το αποθετήριο είναι
επίσης η ερευνητική πλατφόρμα της διπλωματικής εργασίας (Τμήμα Μηχανικών Η/Υ &
Πληροφορικής, Πανεπιστήμιο Πατρών).

## Γρήγορη εκκίνηση

```
PESTO.bat                  μόνο υπαγόρευση
PASTA.bat                  υπαγόρευση + φωνητικές εντολές
python -m pesto doctor     έλεγχος GPU, CUDA, μοντέλων, μικροφώνου
```

Πρώτη εγκατάσταση: `scripts\setup.ps1` (δημιουργεί `venv`, εγκαθιστά εξαρτήσεις,
κατεβάζει τα μοντέλα ~2,3 GB, τρέχει το `doctor`).

| Ενέργεια | Προεπιλογή |
|---|---|
| Υπαγόρευση | κράτα **Right Ctrl** (≥150 ms), μίλα, άφησε |
| Εντολή (PASTA) | ξεκίνα με **«Πάστα,»** ή **«Pasta,»** |
| Ακύρωση εγγραφής ή εντολής | **Esc** |
| Επιβεβαίωση εντολής που ρωτά | **Enter** (ή πες «ναι») |
| Εναλλαγή γλώσσας / μηχανής / λειτουργίας | Ctrl+Alt+Shift+L / E / M |

Τα γρήγορα πατήματα και οι συντομεύσεις με το Right Ctrl (π.χ. Right Ctrl+C)
αναγνωρίζονται ως συντομεύσεις και δεν ξεκινούν υπαγόρευση.

## Τι σημαίνουν οι ενδείξεις

Η κάψουλα κατάστασης στο κάτω μέρος της οθόνης δεν παίρνει ποτέ την εστίαση:

| Ένδειξη | Σημασία |
|---|---|
| πράσινες μπάρες που κινούνται | ακούει — το ύψος ακολουθεί την ένταση της φωνής σου |
| περιστρεφόμενο τόξο | μεταγραφή / εκτέλεση εντολής |
| ✓ πράσινο + χρόνος | το κείμενο μπήκε (π.χ. «312 ms» από το άφημα) |
| μπλε χρώμα, λίστα βημάτων | εντολή PASTA σε εξέλιξη |
| κίτρινο «?» | η εντολή χρειάζεται επιβεβαίωση (Enter / Esc) |
| κόκκινο «!» | αποτυχία, με αιτία (π.χ. «No microphone») |
| γκρι παύλα | ακυρώθηκε ή δεν ακούστηκε ομιλία |

**Αν δεν βλέπεις μπάρες και παίρνεις «No microphone»**: τα Windows δεν βρίσκουν
προεπιλεγμένο μικρόφωνο (π.χ. το ασύρματο headset είναι κλειστό). Άνοιξέ το — το
PESTO το εντοπίζει μόνο του μέσα σε ~3 δευτερόλεπτα. Δες επίσης Πίνακας ελέγχου →
Diagnostics.

### Επιλογή μικροφώνου στις ρυθμίσεις

Αν έχεις πολλαπλά μικρόφωνα ή ασύρματο headset:
1. Άνοιξε το Dashboard (Πίνακας ελέγχου) από το εικονίδιο στην περιοχή ειδοποιήσεων (tray).
2. Πήγαινε στην καρτέλα **Settings** → ενότητα **Audio input** (Είσοδος ήχου).
3. Επίλεξε το επιθυμητό μικρόφωνο από την αναπτυσσόμενη λίστα (ή «Default» για την προεπιλογή των Windows).
4. Πάτησε το κουμπί **↻** δίπλα στη λίστα αν ενεργοποίησες το headset μετά την εκκίνηση.
5. Πάτησε **Save**. Η επιλογή εφαρμόζεται αμέσως στην τρέχουσα εκτέλεση και **αποθηκεύεται μόνιμα στο `config.json` για τις επόμενες συνεδρίες**.

Μπορείς επίσης να δεις τα αναγνωρισμένα μικρόφωνα από γραμμή εντολών:
```
python -m pesto devices
```

## Μηχανές αναγνώρισης

| Μηχανή | Ελληνικά (WER) | Αγγλικά (WER) | Καθυστέρηση (διάμεσος) |
|---|---|---|---|
| **Whisper large-v3-turbo** (προεπιλογή) | **12,3 %** | 5,5 % | ~450 ms για 3 s ομιλίας |
| Parakeet TDT 0.6B (GPU) | 34,9 % | 6,0 % | ~124 ms |

Το Parakeet **δεν μπορεί να γράψει τελικό σίγμα (ς)** — δεν υπάρχει στο λεξιλόγιό του —
γι' αυτό προτείνεται μόνο για αγγλικά.

## Ιδιωτικότητα

Ο ήχος δεν φεύγει ποτέ από τον υπολογιστή. Τα μοντέλα φορτώνονται από την τοπική
κρυφή μνήμη χωρίς δίκτυο. Το κείμενο πληκτρολογείται χωρίς να περάσει από το πρόχειρο
(και όταν χρησιμοποιηθεί πρόχειρο, εξαιρείται από το ιστορικό προχείρου των Windows).
Η τηλεμετρία είναι ένα τοπικό αρχείο SQLite (`data/pesto.db`) που μπορείς να διαγράψεις.
